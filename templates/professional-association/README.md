# Plantilla Institucional para Asociaciones Profesionales

Sistema visual genérico y demostrativo para colegios, consejos y asociaciones profesionales. No representa a una institución real ni contiene logotipos, fotografías, requisitos, políticas o datos oficiales.

## Contextos incluidos

- Portal público editorial y responsive.
- Ejemplo de acceso institucional.
- Ejemplo de área privada de una persona miembro.
- Ejemplo administrativo con bandeja y detalle.
- Componentes para estados informativos, vacíos, errores y confirmaciones.

## Tecnología

- React y TypeScript estricto.
- Vite.
- Tailwind CSS v4.
- React Router v7 mediante rutas hash, para facilitar el despliegue estático.
- Alias `@/*` hacia `src/*`.

## Ejecución

```bash
bun install
bun run dev
```

## Verificación

```bash
bun run typecheck
bun run build
```

Antes de utilizarla, sustituya la marca genérica, los textos pendientes y el espacio fotográfico únicamente con material autorizado.
