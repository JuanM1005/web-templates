# Plantilla de Proveedor Industrial

Base pública y demostrativa para empresas que combinan venta de equipos, selección técnica, mantenimiento e integración de servicios industriales.

## Funcionalidad incluida

- Catálogo con búsqueda y filtros por familia.
- Fichas rápidas con especificaciones genéricas.
- Lista simulada de equipos por cotizar.
- Secciones de servicios, proceso de atención y formulario demostrativo.
- Navegación adaptable para escritorio y móvil.
- Diseño sin imágenes, marcas, contactos ni datos de empresas reales.

## Uso local

```bash
bun install
bun run dev
```

## Verificación

```bash
bun run typecheck
bun run build
```

Todo el contenido, las métricas, los modelos y los datos de contacto son ficticios. El formulario no envía información.
