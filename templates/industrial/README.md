# Plantilla Industrial / Corporativa

Sitio institucional demostrativo enfocado en empresas de ingeniería, manufactura e infraestructura. Incluye secciones de presentación, indicadores, servicios, proyectos filtrables, equipo directivo y contacto.

## Requisitos

- Bun v1.2 o superior

## Instalación y uso independiente

```bash
cd templates/industrial
bun install
```
