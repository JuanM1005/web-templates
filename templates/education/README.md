# Plantilla educativa — Aula Clara

Base ficticia para academias, cursos en línea y capacitación interna. Incluye buscador, filtros de categoría, catálogo, progreso y agenda demostrativa.

```bash
bun install
bun run dev
```

Los cursos, docentes y estadísticas son ficticios. La plantilla no autentica usuarios ni guarda progreso real.
