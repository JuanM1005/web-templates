# Plantilla de Portafolio Profesional

Presentación personal demostrativa con resumen de perfil, proyectos filtrables por especialidad, historial de experiencia, matriz de habilidades y formulario de contacto simulado.

## Instalación y ejecución autónoma

Desde la raíz `web-templates`:

```bash
bun run dev:portfolio
```

Para comprobar y compilar:

```bash
bun run check:portfolio
bun run build:portfolio
```

También puede ejecutarse desde su carpeta:

```bash
cd templates/portfolio
bun install
bun run dev
```
