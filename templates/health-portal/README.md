# Portal de salud — Salud Cerca

Plantilla ficticia para portales de pacientes, clínicas, hospitales o redes de atención. Incluye servicios, citas simuladas, directorio y contenido preventivo.

```bash
bun install
bun run dev
```

No representa al IMSS ni a ninguna institución real. No ofrece diagnóstico, atención de emergencias ni almacenamiento de expedientes médicos.
